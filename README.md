# Personal Portfolio Website

This is my Web Dev I Lab Assignment 2. I made a personal portfolio website using HTML, CSS and a little bit of JavaScript.

## Files in this project
- index.html - the main page (header, about, skills, projects, contact, footer)
- style.css - all the CSS is in this file (external stylesheet)
- script.js - JavaScript for the contact form
- images - folder for images

## What I used in this project
- Google Font (Poppins) for all the text
- Colors: dark blue, red and yellow (I used hex codes)
- Navbar with hover effect. It is sticky so it stays on top when we scroll
- Margin, padding, border and box shadow for spacing between sections
- Skills table with alternate row colors
- Project cards, buttons with border radius and hover effect
- Back to Top button using position: fixed
- hr line to separate the sections
- Smooth scrolling when we click on the navbar links
- Contact form with labels, placeholders and validation (required and email type)
- Media query so the page looks fine on small screens also

## Contact form
When someone fills the form and clicks Send, WhatsApp opens with the name, email and message already typed. Then they just have to press send in WhatsApp. I did this using JavaScript in script.js.

## How to run
Download or clone the project and open index.html in any browser. Keep index.html, style.css and script.js in the same folder.
